для того чтобы изменить бд нужно добавить необходимые поле в модель таблицы (если она уже создана), 
если нужно добавить новую таблицу то нужно создать новую модель и добавить ее в dbContext

после этого команда для генерации миграций:
dotnet ef migrations add НАЗВАНИЕ_МИГРАЦИИ

после генерации заходим в папку Migrations и проверяем файл 12398172938719_НАЗВАНИЕ_МИГРАЦИИ.cs 
на правильность, нам два блока up и down, обновление и откат соответственно (если в бд есть данные которые страшно потерять, то делаем бэкап).
далее имеет смысл посмотреть фыайл Snapshot Это по сути скриншот нынешней бд
если все ок, то применяем миграцию к бд командой: 
dotnet ef database update

если в up И down написано что-то не то, то можно либо отредактировать эти методы, 
либо удалить файл с ними, поменять модель и сгенерировать миграции еще раз

удалить последнюю миграцию (если не применена):
dotnet ef migrations remove

откат БД на конкретную миграцию:
dotnet ef database update <MigrationName> (или 0 для удаления всех)

список миграций в проекте:
dotnet ef migrations list
